# Deployment Guide

## Pre-Deployment Checklist

- [ ] All tests passing (run `bundle exec rspec`)
- [ ] Environment variables configured
- [ ] OAuth credentials obtained (Google, GitHub)
- [ ] Database migrations ready
- [ ] Tailwind CSS built
- [ ] Production secrets generated

## Environment Setup

### 1. Create `.env` file (or configure hosting environment variables)

```bash
# Copy example
cp .env.example .env

# Edit with your values
RACK_ENV=production
SESSION_SECRET=<generate-with-openssl-rand-hex-64>
GOOGLE_CLIENT_ID=<your-google-client-id>
GOOGLE_CLIENT_SECRET=<your-google-client-secret>
GITHUB_CLIENT_ID=<your-github-client-id>
GITHUB_CLIENT_SECRET=<your-github-client-secret>
```

### 2. Generate Secure Session Secret

```bash
ruby -e "require 'securerandom'; puts SecureRandom.hex(64)"
```

## Docker Deployment

### Production Docker Setup

1. **Build image**:
   ```bash
   docker build -t v7cms:latest .
   ```

2. **Run container**:
   ```bash
   docker run -d \
     -p 80:9292 \
     -v $(pwd)/db:/app/db \
     -e RACK_ENV=production \
     -e SESSION_SECRET=<your-secret> \
     -e GOOGLE_CLIENT_ID=<id> \
     -e GOOGLE_CLIENT_SECRET=<secret> \
     -e GITHUB_CLIENT_ID=<id> \
     -e GITHUB_CLIENT_SECRET=<secret> \
     --name v7cms \
     v7cms:latest
   ```

3. **Run migrations**:
   ```bash
   docker exec v7cms bundle exec rake db:migrate
   ```

### Docker Compose Production

```yaml
# docker-compose.prod.yml
version: '3.8'
services:
  web:
    build: .
    ports:
      - "80:9292"
    volumes:
      - ./db:/app/db
      - ./public:/app/public
    environment:
      - RACK_ENV=production
      - SESSION_SECRET=${SESSION_SECRET}
      - GOOGLE_CLIENT_ID=${GOOGLE_CLIENT_ID}
      - GOOGLE_CLIENT_SECRET=${GOOGLE_CLIENT_SECRET}
      - GITHUB_CLIENT_ID=${GITHUB_CLIENT_ID}
      - GITHUB_CLIENT_SECRET=${GITHUB_CLIENT_SECRET}
    restart: unless-stopped
```

Deploy:
```bash
docker-compose -f docker-compose.prod.yml up -d
docker-compose -f docker-compose.prod.yml exec web bundle exec rake db:migrate
```

## Shared Hosting Deployment (DreamHost, etc.)

### Prerequisites
- SSH access to hosting account
- Ruby 3.x installed
- Ability to run FastCGI applications

### Steps

1. **Enable FastCGI gem**:

   Edit `Gemfile`, uncomment:
   ```ruby
   gem 'fcgi', '~> 0.9'
   ```

2. **Upload files**:
   ```bash
   # Via git
   git clone <your-repo-url> ~/example.com
   cd ~/example.com

   # Or via FTP/SFTP - upload all files except:
   # - .git
   # - db/*.db (development databases)
   # - public/css/output.css (will regenerate)
   # - bin/tailwindcss (platform-specific)
   ```

3. **Install dependencies**:
   ```bash
   bundle install --deployment --without development test
   ```

4. **Build Tailwind CSS**:
   ```bash
   # Download Tailwind CLI for your platform
   curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-linux-x64
   chmod +x tailwindcss-linux-x64
   ./tailwindcss-linux-x64 -i public/css/input.css -o public/css/output.css --minify
   ```

5. **Configure environment**:
   ```bash
   # Create .env file
   cat > .env << 'EOF'
   RACK_ENV=production
   SESSION_SECRET=<your-generated-secret>
   GOOGLE_CLIENT_ID=<your-id>
   GOOGLE_CLIENT_SECRET=<your-secret>
   GITHUB_CLIENT_ID=<your-id>
   GITHUB_CLIENT_SECRET=<your-secret>
   EOF

   chmod 600 .env
   ```

6. **Run migrations**:
   ```bash
   RACK_ENV=production bundle exec rake db:migrate
   ```

7. **Create dispatch.fcgi**:
   ```ruby
   #!/usr/bin/env ruby
   require 'fcgi'

   ENV['RACK_ENV'] = 'production'

   require_relative 'config.ru'

   FCGI.each_cgi do |cgi|
     rack_response = Rack::Handler::FastCGI.run(cgi)
   end
   ```

8. **Make executable**:
   ```bash
   chmod +x dispatch.fcgi
   ```

9. **Configure .htaccess**:
   ```apache
   RewriteEngine On
   RewriteBase /

   # Redirect all requests to dispatch.fcgi
   RewriteCond %{REQUEST_FILENAME} !-f
   RewriteRule ^(.*)$ dispatch.fcgi/$1 [QSA,L]
   ```

10. **Set OAuth redirect URLs**:
    - Google: `https://yourdomain.com/auth/google_oauth2/callback`
    - GitHub: `https://yourdomain.com/auth/github/callback`

11. **Test deployment**:
    ```bash
    curl https://yourdomain.com/health
    ```

## Post-Deployment

### 1. Verify Application

- [ ] Homepage loads: `https://yourdomain.com/`
- [ ] Admin panel accessible: `https://yourdomain.com/admin.html`
- [ ] Health check passes: `https://yourdomain.com/health`
- [ ] OAuth login works (Google)
- [ ] OAuth login works (GitHub)
- [ ] Can create posts
- [ ] Can view posts on public site

### 2. Create First Admin User

1. Navigate to `/admin.html`
2. Sign in with Google or GitHub
3. Verify you can access the admin panel
4. Create your first post

### 3. Security Hardening

- [ ] Ensure `.env` is not web-accessible
- [ ] Verify OAuth credentials are correct
- [ ] Check HTTPS is enforced
- [ ] Review file permissions (644 for files, 755 for directories)
- [ ] Ensure `db/` directory is writable

### 4. Monitoring

Monitor application logs:
```bash
# Docker
docker-compose logs -f web

# Shared hosting
tail -f ~/logs/<domain>/http/error.log
```

## Backup Strategy

### Database Backups

```bash
# Backup SQLite database
cp db/production.db db/backups/production-$(date +%Y%m%d-%H%M%S).db

# Automated daily backup (cron)
0 2 * * * cd /path/to/v7cms && cp db/production.db db/backups/production-$(date +\%Y\%m\%d).db
```

### Full Backups

```bash
# Create full backup
tar -czf v7cms-backup-$(date +%Y%m%d).tar.gz \
  --exclude='*.log' \
  --exclude='tmp/*' \
  --exclude='.git' \
  /path/to/v7cms
```

## Rollback Procedure

### Docker Deployment

```bash
# Stop current container
docker-compose down

# Restore database backup
cp db/backups/production-<timestamp>.db db/production.db

# Start with previous version
docker-compose up -d
```

### Shared Hosting

```bash
# Restore from git
git checkout <previous-commit>
bundle install --deployment

# Restore database
cp db/backups/production-<timestamp>.db db/production.db

# Rollback migrations if needed
RACK_ENV=production bundle exec rake db:rollback STEP=1
```

## Troubleshooting

### Issue: 500 Internal Server Error

**Check**:
- Application logs
- File permissions
- Environment variables set correctly
- Database file writable

**Solution**:
```bash
# Check logs
tail -f logs/production.log

# Verify permissions
chmod 644 app/cms.rb
chmod 755 db/
chmod 644 db/production.db
```

### Issue: OAuth Login Not Working

**Check**:
- OAuth credentials correct in `.env`
- Redirect URLs match OAuth app settings
- HTTPS enabled

**Solution**:
- Verify environment variables: `env | grep GOOGLE`
- Check OAuth app settings in Google/GitHub console
- Ensure redirect URLs include correct domain

### Issue: Static Assets Not Loading

**Check**:
- Tailwind CSS built: `ls -lh public/css/output.css`
- File permissions: `chmod 644 public/css/output.css`
- `.htaccess` configured to allow static files

**Solution**:
```bash
# Rebuild Tailwind
./bin/tailwindcss -i public/css/input.css -o public/css/output.css --minify
```

### Issue: Database Locked

**Cause**: SQLite can't handle high concurrent writes

**Solution**:
- Reduce concurrent requests
- Consider PostgreSQL/MySQL for high traffic
- Use connection pooling

## Performance Optimization

### Enable Gzip Compression

Add to `.htaccess`:
```apache
<IfModule mod_deflate.c>
  AddOutputFilterByType DEFLATE text/html text/css application/javascript application/json
</IfModule>
```

### Cache Static Assets

Add to `.htaccess`:
```apache
<IfModule mod_expires.c>
  ExpiresActive On
  ExpiresByType image/jpg "access plus 1 year"
  ExpiresByType image/jpeg "access plus 1 year"
  ExpiresByType image/gif "access plus 1 year"
  ExpiresByType image/png "access plus 1 year"
  ExpiresByType text/css "access plus 1 month"
  ExpiresByType application/javascript "access plus 1 month"
</IfModule>
```

### Database Optimization

```bash
# Optimize SQLite database
sqlite3 db/production.db "VACUUM;"
sqlite3 db/production.db "ANALYZE;"
```

## Scaling

### Moving to PostgreSQL/MySQL

1. Update `Gemfile`:
   ```ruby
   # Replace sqlite3 with:
   gem 'pg', '~> 1.5'  # PostgreSQL
   # OR
   gem 'mysql2', '~> 0.5'  # MySQL
   ```

2. Update `config/database.yml`:
   ```yaml
   production:
     adapter: postgresql
     database: v7cms_production
     username: <%= ENV['DB_USER'] %>
     password: <%= ENV['DB_PASS'] %>
     host: <%= ENV['DB_HOST'] %>
     pool: 5
   ```

3. Export/Import data:
   ```bash
   # Dump from SQLite
   sqlite3 db/production.db .dump > dump.sql

   # Import to PostgreSQL
   psql v7cms_production < dump.sql
   ```
